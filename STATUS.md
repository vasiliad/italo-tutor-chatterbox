## Что уже выяснено (без генерации звука)
- Токенайзер: знаки ударения U+0300/U+0301 — отдельные токены, `[UNK]` нет; русские ударения модель видела при обучении.
- Иврит: все огласовки и знак ole есть в словаре, но Chatterbox вызывает `Dicta()` без пути к модели → падает →
  иврит уходит без огласовок. Dicta ошибается на омографах даже при ясном контексте (הַבֹּוקֶר вместо הַבּוֹקֵר «ковбой»,
  הַסֵּפֶר вместо הַסַּפָּר «парикмахер»).
- Вывод владельца и наш: неоднозначность снимает только тот, кто знает смысл («мозг»), явной разметкой; для ученицы —
  ещё и картинкой. Контекст помогает не всегда.

## Ключи Gemini (со слов владельца, 2026-09-28)
- 3 ключа, по нашим моделям без дневного лимита. Ограничения: 65 тыс. токенов в минуту на ключ,
  Live-сессия обрывается раз в 10 минут (у нас сессия = один вопрос, это не мешает), не чаще ~30 запросов/мин.
- На Kaggle — отдельные секреты `GEMINI_API_KEY`, `GEMINI_API_KEY_2`, `GEMINI_API_KEY_3` (в один секрет
  через пробел не сохраняются). `expert_listen.py` ходит по ключам по кругу. По документации лимиты считаются **на проект, а не на ключ**
  (docs/research/gemini_live_api.md §8), поэтому темп `--per-min` по умолчанию общий; `--per-key` — только
  если ключи из разных проектов. Точных цифр лимитов Live в документации нет (смотреть в AI Studio).
- Запуск через API видит секреты только после того, как версию один раз сохранили из редактора (Save Version).
