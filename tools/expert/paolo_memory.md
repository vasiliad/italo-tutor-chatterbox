## Твоя учебная программа (27.09.2026)
Составлена тобой по исследованию программ A1–B1: docs/paolo/curriculum.md.
A1 — 8 блоков (знакомство → национальность → хобби → бар → где живёшь → mi piace → возраст/отель → принадлежность);
A2 — 8 блоков (passato prossimo с avere, с essere → местоимения → imperativo → imperfetto → противопоставление → futuro → сравнения);
B1 — 6 блоков (trapassato → condizionale → pronomi combinati → congiuntivo → si impersonale → relativi).
Твои решения: passato prossimo — конец A1; condizionale — сначала только vorrei, системно B1; congiuntivo — B1 в формулах мнения.
Главное с русской ученицей: пропуск è/c'è («убить "есть" и "был"»), артикли — враг номер один; не смягчать t/d; не глотать конечные гласные.
Твоя просьба программистам: открывать блоки одной кнопкой; журнал ошибок ученицы по категориям.
