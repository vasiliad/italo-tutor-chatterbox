`coord/hebrew/ui_spec.md` (экраны и контракт UI↔движок), `coord/hebrew/prompts_data.md` (промпты и данные).
Уровней у нас 3 (A1, A2, B1), учитель — Паоло. Уже сделано: ядро метода (№7: программа от учителя, план и дрилл

встреча голосом при запуске, фолбэк 3.1→3.8, пул ключей, субтитры с ударениями, SM-2 с прогоном, macOS/Linux.

## Этап A — надёжность часового урока (движок, без новых экранов)
1. Реконнект по таблице Хавы: классификация закрытия (region / quota → смена ключа без паузы / auth / net →
   бэкофф с джиттером до 30 с / clean-close / resume_rejected), после 10 неудач или 180 с — «нет связи» и повтор
   каждые 30 с; VPN-манёвры только между сессиями; перед connect — жив ли xray.
2. OneShot (план, программа, резюме, вердикты): очередь по одному, до 3 раундов «продолжи ровно с этого места»,
   повтор немого ответа, отдельный ключ (не делить квоту урока), не ждать 120 с при закрытом сокете.
3. Дрилл: активен только после базы; ответ не про стимул (пересечение слов < 0,5) → тот же стимул (≤3 раз);
   нет вердикта → один запрос вердикта; «почти» ≠ верно.
4. Промпт Паоло по разбору Хавы: семантика каждого служебного сообщения (3 вида ВРЕМЯ, когда начинать дрилл,
   «нет отметки = время есть», не произносить «ПЛАН:»), «Giusto» = вся фраза слово в слово, формулировка для
   медленного ответа, «требовательный, а не чирлидер», не молчать ученицу >20 с, каждый ход — с заданием,
   избегание конструкции = ошибка, ≤1–2 исправления на реплику, формат ошибки интонации; `{{LETTERS}}` —
   ловушки письма (двойные, h в ho/hai, è/e, qu/cu, апострофы, акценты). Разделы «Как говорят на улице» и
   «Живая Италия» (новости, песни без полных текстов). `TRAPS/DRILL_EXAMPLE/LETTERS` — генерирует Паоло раз на
   уровень, правила — только руками. `metodo.txt` дополнить до объёма `ulpan_method`; `club_regole.txt`.
5. Метрики урока: доля речи ученицы (≥0,45), число эхо служебного, дрилл; журнал в архив урока.

## Этап B — экраны по спецификации Хавы (`ui_spec.md` §8)
1. `TutorEngine` (методы + поток событий) и один notifier состояния; `FakeTutorEngine` для widget-тестов.
2. Урок: пузыри-субтитры (it/ru сегменты, ударения), пилюля «слушаю/говорит/думает/нет связи», часы с
   овертаймом, **открытый микрофон с VAD** (кнопка-рация — опцией), текст Enter/Shift+Enter, 📎, переключатель
   «в наушниках — можно перебивать / без — по очереди», mute (Ctrl+M), баннер и журнал связи, оверлей
   финализации (окно не закрывается до конца).
3. Правая панель: Цель, Ошибки, Дрилл (точки+счёт), Темп, План, Резюме, Домашка, Связь. Доска:
   `board_write(it, ru, note)`, `board_variants` (gergo/colloquiale/neutro/formale), «было → надо»,
   `board_image` (Викисклад с автором и лицензией), дедуп, ≤24 строк.
4. **«Курс» — главный экран**: лестница A1–A2–B1, карточка «сейчас» [Начать урок][Домашка N][Повторить N],
   темы → цели (new/working/mastered), строка статистики (серия, цели, удержание, словарь говорит/понимает).
5. Домашка: 9 типов (shadow, read, oral RU→IT, write, listen, dictation блоком, cloze, chat), судья — Паоло
   (ВЕРНО/ПОЧТИ/НЕВЕРНО, дифф по словам, 3 попытки, «судья недоступен» ≠ ошибка); «Аудирование» и
   «Грамматика» вливаются как типы.
6. История (транскрипт/ошибки/домашка/план, ▶ запись, «↻ повторить урок»); запись занятий (обе стороны).
7. Клуб вместо «Чата»: тема → 2 списка слов → разговор только с субтитрами, без плана/дрилла/домашки.
8. Экзамен/тест уровня: Lettura · Lingua · Scrittura · Orale (шаблон CILS/CELI), переключает уровень курса.
9. Мастер первого запуска (один раз) внутри startup: наушники, устройства, проверка наушников **голосом Паоло**
   (не тон), микрофон с порогом, «скажите Ciao», уровень или тест. 10. Настройки: ключи (наше) + группы Хавы.

## Этап C — данные итальянского
Словарь по CEFR (Profilo/Sillabo, Kelly, NVdB De Mauro, SUBTLEX-IT, Morph-it! — только списки лемм, лицензии
проверить), 6 новых + 4 повтора за урок; «улица» ~600 единиц (регистр, регион, жесты; слоты «говорить 3 /
понимать 2», каждый 7-й урок — «урок улицы», 18+ выключено); песни 7 на уровень — только метаданные
(Челентано и др.), песня каждый 3–4-й урок. Схемы — `prompts_data.md` §3–4.
