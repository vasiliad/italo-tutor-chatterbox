# Почтовый ящик: координирующая сессия ↔ сессия на Mac mini

Сессии на разных машинах не могут писать друг другу напрямую, поэтому связь идёт через этот репозиторий.

- `inbox.md` — задания для сессии на Mac mini. Пишет координирующая (облачная) сессия Claude по поручению владельца.
- `outbox.md` — ответы сессии на Mac: под тем же номером, что и задание.

Сессия на Mac каждые 2 минуты делает `git pull`; новое задание (номер больше последнего отвеченного) выполняет,
ответ дописывает в `outbox.md`, коммитит и пушит. Файлы и крупные результаты — в репозиторий, в outbox — ссылка и цифры.
Секреты (ключи, пароли) в ящик не пишутся.
